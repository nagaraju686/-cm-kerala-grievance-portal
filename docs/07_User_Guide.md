
# User Guide

## 1. Introduction

CM Kerala is a grievance management portal prototype designed to help citizens submit complaints and track their progress.

The application supports three roles:

- Citizen
- CMO Administrator
- Department Officer

## 2. Citizen Guide

### Registration

1. Open the application.
2. Navigate to Register.
3. Enter name, email, mobile number, and password.
4. Submit the registration form.

### Login

1. Open the Login page.
2. Enter registered email and password.
3. Click Login.

### Submit a Grievance

1. Open Citizen Dashboard.
2. Click Submit New Grievance.
3. Select district and category.
4. Enter subject and description.
5. Attach an optional image or PDF.
6. Submit the grievance.
7. Save the generated reference ID.

### Track a Grievance

1. Open the tracking page.
2. Enter the grievance reference ID.
3. View current status and available history.

### Submit Feedback

1. Login to Citizen Dashboard.
2. Find a resolved grievance.
3. Select a rating from 1 to 5.
4. Enter comments.
5. Submit feedback.

## 3. CMO Administrator Guide

### Login

Use the authorized CMO demo account during local testing.

### Dashboard

The CMO dashboard displays grievance statistics and available filters.

### View Grievances

Administrators can review grievance details, district, category, priority, status, and attachments.

### Assign Grievances

1. Open Assign Grievance.
2. Select a grievance.
3. Select a department.
4. Select an officer.
5. Enter assignment remarks.
6. Submit the assignment.

### Review Officer Reports

1. Open CMO Reports.
2. View submitted officer reports.
3. Click Review Report.

### Resolve Grievances

After reviewing the officer report, the CMO administrator can resolve the grievance.

## 4. Department Officer Guide

### Login

Use the authorized officer demo account during local testing.

### View Assignments

Open Officer Dashboard to see assigned grievances.

### Update Status

Select Under Review or In Progress and click Update Status.

### Submit Action-Taken Report

1. Open the assigned grievance.
2. Enter investigation details and action taken.
3. Click Submit Action Taken Report.

The CMO administrator can review the submitted report.

## 5. Grievance Status Definitions

| Status | Description |
|---|---|
| Submitted | Citizen submitted a grievance |
| Under Review | Grievance is being reviewed |
| In Progress | Department is working on the grievance |
| Resolved | Grievance has been resolved |
| Reopened | Previously resolved grievance reopened |

## 6. Important Notes

- Keep the grievance reference ID safe.
- Provide accurate complaint information.
- Do not upload sensitive or unnecessary documents.
- Use the correct account for each role.
- This project is an educational prototype and not an official government service.
